# Steady interface

## Approved direction

Practical, modern, light phone interface. Warm off-white surface, forest-green primary actions, muted coral primary muscle regions, green supporting regions. No promotional slogans, fake progress, or duplicated workout headings.

## Hierarchy

Day and date → selected week → one workout summary → anatomical target map → warm-up disclosure → ordered exercise prescriptions → primary action. Keep instruction content available without crowding the overview.

## Interaction

44px minimum touch targets, explicit field labels, visible keyboard focus, useful empty/error states, readable 14–16px exercise text. Date navigation must not discard a draft. Timed holds use seconds, walkouts use full cycles; no invented load conversions.

## Muscle maps

Front and back schematic regions, not measured activation, fatigue, or recovery. The source diagram groups deltoid heads and back regions. Attribution and MIT notice must ship with adapted assets.
